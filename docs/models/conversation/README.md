# Voice conversation

These workflows use different input and timing contracts.

- [Nemotron](nemotron.md): duplex voice conversation and offline input.
- [PersonaPlex](personaplex.md): duplex conversation with voice and role prompts.
- [Ming Audio](ming_audio.md): one audio question and a spoken answer.
- [Qwen3 Omni](qwen_omni.md): recorded speech or text with streamed spoken responses.
- [MiniCPM-o](minicpm.md): live duplex conversation and recorded or text questions with spoken answers.
