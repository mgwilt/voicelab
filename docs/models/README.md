# Model index

Read only the guide for the model you need.
Each guide separates use, measurements, implementation, and evidence limits.

- [Nemotron](nemotron.md): duplex voice conversation and offline audio input; MLX runtime.
- [Sesame](sesame.md): contextual speech synthesis with optional reference audio; PyTorch runtime.
- [Breeze](breeze.md): speech synthesis controlled by voice instructions; MLX runtime.

A runtime name does not prove support on every device.
Read each guide's limits before you compare performance or add a platform.
Shared RTF definitions are in [measurements](../usage/measurements.md).
