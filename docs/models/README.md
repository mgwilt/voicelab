# Model index

Choose the workflow, then read the guide for your model.

- [Speech synthesis](synthesis/README.md): text, voice controls, and output RTF.
- [Voice conversation](conversation/README.md): microphone sessions and audio questions.

All runtimes execute locally. Model weights download on first use.
Each guide identifies controls, hardware requirements, provenance, and verification limits.
Read [measurements](../usage/measurements.md) before comparing results.

Each model guide records generation defaults and their sources, reviewed on 2026-10-30.
Use explicit recommendations where available; otherwise use published configurations or labeled examples.
Frame, token, and call limits are lab resource bounds, not upstream quality recommendations.
Seeds support repeatable comparisons within a runtime. They do not guarantee parity across devices.
